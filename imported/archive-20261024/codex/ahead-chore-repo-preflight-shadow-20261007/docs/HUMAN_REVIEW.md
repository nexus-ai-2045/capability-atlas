# 人間レビュー判断材料

## 今回レビューするもの

- 統合導線が「全体把握 → 原因確認 → 安全実験」になっているか。
- 状態の意味が、色だけに依存せず理解できるか。
- 事実・推論・不明が混ざって見えないか。
- 人間レビュー境界が不足していないか。

## 次フェーズで承認が必要なもの

1. 実環境コレクターが読むパスとコマンド。
2. 自動スモークのallowlist。
3. 定期実行の頻度と証跡保持期間。
4. private GitHubリポジトリ作成と初回push。

## 現在は承認対象外

公開、外部共有、認証、設定変更、課金、外部API呼び出しは実装・実行していません。
